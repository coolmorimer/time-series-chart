# Four series chart

SVG-компонент без runtime-зависимостей, повторяющий предоставленный видеореференс: розовый фон демо, жёлтая area, зелёная spline, фиолетовая line с квадратами, синие bar и общая подсказка по дате.

## Запуск

Требуется Node.js 22.12+.

```sh
git clone https://github.com/coolmorimer/four-series-chart.git
cd four-series-chart
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://127.0.0.1:5173).

```sh
npm test
npm run build
npm run preview
```

`dist/` — статическая production-сборка.

## Инициализация четырьмя последовательностями

В проекте со сборщиком Vite импортируйте компонент. CSS импортируется самим модулем. Контейнеру задайте высоту и ширину; фон задаётся контейнером.

```html
<div id="chart" style="width:590px;max-width:100%;height:294px;background:#fbe1e5"></div>
```

```js
import { createTimeSeriesChart } from './src/chart.js';

const chart = createTimeSeriesChart(document.querySelector('#chart'), {
  area: [
    { time: '2026-06-10', value: 2.04 },
    { time: '2026-06-12', value: 44.36 },
  ],
  spline: [
    { time: '2026-06-10', value: 610.78 },
    { time: '2026-06-12', value: 161.47 },
  ],
  line: [
    { time: '2026-06-10', value: 3 },
    { time: '2026-06-12', value: 36 },
  ],
  bar: [
    { time: '2026-06-10', value: 0.68 },
    { time: '2026-06-12', value: 1.23 },
  ],
}, {
  series: {
    area: { label: 'Cost', color: '#fff89b' },
    spline: { label: 'ROI confirmed', color: '#078900' },
    line: { label: 'Conversions', color: '#b900ff' },
    bar: { label: 'CPA', color: '#3c70ff', domain: [0, 100] },
  },
});

// chart.setData({ area: [...], spline: [...], line: [...], bar: [...] });
// chart.destroy(); // при размонтировании контейнера
```

## Контракт данных и поведение

- Все четыре ключа обязательны; массивы могут быть пустыми, иметь разные даты и длины.
- `time`: ISO-дата (`YYYY-MM-DD`), ISO timestamp с часовым поясом или Unix timestamp **в миллисекундах**. Подсказка показывает дату в UTC.
- `value`: конечное число или `null`. Явный `null` разрывает линию; отсутствующая дата не добавляет искусственные нули. В подсказке отсутствующее значение отображается как `—`.
- Данные сортируются без изменения исходных массивов; повторные даты внутри одного ряда и невалидные значения вызывают исключение.
- Горизонтальная шкала — реальное время, вертикальные шкалы независимые. По умолчанию каждый ряд масштабируется от нуля с запасом 20% сверху; отрицательные значения поддерживаются. `series.<type>.domain: [min, max]` задаёт фиксированный диапазон. Значения за его пределами обрезаются границами SVG.
- В демо CPA имеет диапазон `[0,100]`, чтобы маленькие столбцы выглядели как в референсе. Отдельные масштабы означают, что высоту разных рядов нельзя сравнивать как одну единицу измерения.
- Указатель выбирает ближайшую дату, подсказка объединяет четыре ряда; при уходе указателя скрывается. Касание выбирает дату. Tab фокусирует график; ←/→, Home/End выбирают дату, Escape скрывает подсказку.
- `ResizeObserver` перестраивает SVG при изменении размера. `destroy()` отключает наблюдение и удаляет компонент.
- Опции: `locale` (по умолчанию `ru-RU`), `formatValue(value, type)`, `series` с `label`, `color`, `domain`.

## Соответствие референсу

Размер графика в демо — 592×295 px. Оси и сетка скрыты, область полупрозрачна; spline использует монотонную кубическую интерполяцию без выбросов, line — прямые отрезки. Общая подсказка имеет белый фон, скругление и тень; выбранные точки подсвечены полупрозрачными кругами.

Числа, читаемые на скриншоте и кадрах видео, сохранены. Остальные демонстрационные значения приблизительные: исходные четыре массива не предоставлены. Редактор строки таблицы не входит в компонент графика. Исходные личные медиа не включены в репозиторий.

## Проверки

`npm test`: сортировка, нули, пропуски, отклонение некорректных значений и повторных дат, прохождение spline через точки. `npm run build`: production-сборка.
